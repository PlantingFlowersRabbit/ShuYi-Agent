# v0.141 Verification

## Required Evidence

- On the model configuration page, click remote save, local save, test link, and start service; record visible success or failure feedback for each action.
- On the voice library page, click save voice and delete selected voices; record visible success or failure feedback, including the empty-selection case.
- Click generate voice with the local VoiceDesign service available and verify the API returns `generation_status=succeeded` and playable audio.
- Repeat with VoiceDesign unavailable and verify the API returns `generation_status=substitute`, a playable placeholder wav, and the `Qwen3-TTS-12Hz-1.7B-VoiceDesign` requirement.
- Confirm the `仅使用声纹` checkbox has visible Chinese explanatory text.

## Known Boundary

The previous v0.14 placeholder happened because the generated-voice endpoint did not call a model. v0.141 now attempts the VoiceDesign endpoint first, then falls back with an explicit reason when the configured service does not support it.
