# NovelVoice-Agent v0.3.4 验收标准

## 总通过口径

v0.3.4 通过验收，需要同时满足：

- v0.12 的大小说上传、章节懒加载、进度条和左右独立滚动仍然有效。
- 前端只展示 3 个 AI 智能体入口：`AI小说格式解析`、`AI角色分析` 和 `AI角色匹配`。
- `AI小说格式解析` 使用 DeepSeek 配置时，测试链接和格式解析必须兼容用户填写 `https://api.deepseek.com/v1`，不得误报 `Not Found`。
- 当前章节区左 1/2 显示完整章节正文，右 1/2 只显示划分语句、角色选择和音频生成控件，不再展示段落卡片。
- 左侧小说章节区可收起为窄边栏，收起后当前章节正文和台词工作区获得更多横向空间。
- AI角色匹配前自动同步当前章节并生成可编辑语句草稿；前端不再提供 `确认无误` 或独立 `AI语句划分` 按钮。
- `AI角色匹配` 在同一个批量 Agent 响应中完成必要的语句划分和角色选择，而不是调用独立前端分句流程。
- 语句文本的音频生成控件仅保留 `选择角色` 和 `音频生成`；不再展示语言、情绪、仅使用声纹、语速、音量和其他控制文本。
- 语句文本的 `选择角色` 初始状态为空，不默认选中角色列表第一项。
- 音频按钮语义为“音频生成”，使用所选角色绑定音色的参考音频和参考文本发起请求。
- 新增音色绑定到新增角色后，音频生成必须使用当前选中音色的参考音频和语音具体内容。
- 音频生成模块支持添加和删除；添加入口位于右侧语句面板。
- 本地 Qwen3-TTS 不可用时，后端返回可播放占位音频和清晰状态，不把原始失败 JSON 暴露给前端。
- 音色资源库可独立滚动，角色列表可新增角色，角色音色播放按钮为图标且可触发播放。
- 音色资源库添加参考音频使用文件选择；生成音色先展示进度和可播放预览，保存后才进入资源库。
- 模型配置页只展示远端模型 Base URL、模型名称、api_key，以及本地模型 BASE_URL、模型权重路径；远端和 AI小说格式解析智能体可测试链接，本地可启动服务。
- 模型配置页和音色资源库页的保存、删除、测试、启动操作必须显示成功或失败反馈。
- 生成音色必须先尝试 VoiceDesign 模型；不可用时返回可播放占位 wav 并明确提示需要 `Qwen3-TTS-12Hz-1.7B-VoiceDesign`。
- 音频生成请求超出本地 TTS 单条文本边界或超时时，前端必须展示明确原因，提示用户缩短文本或拆成多条音频生成。
- 项目为桌面端工作台，不交付移动端适配。
- 文档、spec、资源说明、agent 配置完整，资源有来源和许可证。

## 一、仓库和文档

- **AC-DOC-01** 仓库包含 `AGENTS.md`，并说明目标、结构、实现约束、子 Agent 协作和强制开发流程。
- **AC-DOC-02** 仓库包含兼容入口 `AGENT.md`，并指向 `AGENTS.md`。
- **AC-DOC-03** `spec/` 包含当前版本目标、产品范围、架构合约、LLM 合约和 TTS 合约。
- **AC-DOC-04** `docs/index.md` 包含所有新增 docs 文档链接。
- **AC-DOC-05** `docs/experience-library/` 包含入口、主动规则和 lessons。
- **AC-DOC-06** `.codex/agents/` 包含 builder、test-author、acceptance-checker、visual-reviewer、audio-reviewer 和 reviewer。

## 二、产品流程

- **AC-FLOW-01** v0.25 明确是人工主导的人机协作版。
- **AC-FLOW-02** txt 小说导入后按中文章节或数字编号章节正则拆分。
- **AC-FLOW-03** 点击 `AI小说格式解析` 之前，右侧不得渲染具体章节内容；选择某个章节后才加载该章正文。
- **AC-FLOW-04** 前端当前章节左半区显示完整章节正文；右半区只显示划分语句和角色匹配结果。
- **AC-FLOW-05** AI角色匹配前由前端自动同步当前章节内部段落状态并准备整段语句草稿。
- **AC-FLOW-06** AI角色匹配不得请求不存在的后端 paragraph 状态，不得出现 `paragraph not found`。
- **AC-FLOW-07** AI角色匹配产生的语句划分和角色结果必须嵌套在来源段落内，且可人工编辑。
- **AC-FLOW-08** 语句文本、角色和音频生成必须有前端可见功能标签；语言、情绪、仅使用声纹、语速、音量、其他控制文本不得出现在语句音频生成 UI；选择角色初始状态必须为空。
- **AC-FLOW-09** 语句文本 UI 不展示 `voice_cloning` / `voice_design` 模式选择框。
- **AC-FLOW-10** 主页面 UI 参考 Unitale 浅色工作台风格，不出现明显文本重叠或按钮溢出。
- **AC-FLOW-11** 主页面必须展示上传小说、小说格式解析、AI角色匹配和语音生成四个进度条。
- **AC-FLOW-12** 上传大体量小说后，左侧小说章节区不得渲染完整小说正文，只展示开头预览，并保留完整文本用于小说格式解析。
- **AC-FLOW-13** 左侧和右侧工作区必须使用独立纵向滚动条，不把整个页面作为主要滚动容器。
- **AC-FLOW-14** 点击 `AI角色匹配` 时，每个内部段落必须自动准备一条整段落 `语句文本` 草稿。
- **AC-FLOW-15** 当前章节 UI 不得再展示段落卡片、段落折叠/删除控件或独立 `AI语句划分` 按钮；分句由 `AI角色匹配` 统一完成。

## 三、角色和声音

- **AC-ROLE-01** 默认角色列表由音色资源库驱动，不再使用三个烟测占位角色卡。
- **AC-ROLE-02** 每个角色卡包含姓名、绑定音色、音色描述、语音具体内容和图标播放按钮。
- **AC-ROLE-03** 角色列表必须支持新增角色，并同步到后端角色 API。
- **AC-ROLE-04** 角色音色播放按钮必须是图标按钮，点击后播放绑定音色参考音频或给出可读失败状态。
- **AC-ROLE-05** 音色资源库必须支持列表、添加、生成、修改、勾选删除和参考音频播放。
- **AC-ROLE-06** 生成音色若使用本地替身，必须标注为替身，不得宣称真实 voice design 质量。

## 四、LLM / 角色匹配分句

- **AC-LLM-01** provider registry 和后端 LLM 合约继续保留 SiliconFlow `Qwen/Qwen3-8B` 边界。
- **AC-LLM-02** 后端模型输出仍必须是严格 JSON，并通过文本守恒校验。
- **AC-LLM-03** v0.3.4 前端必须先同步当前章节内部段落状态，再由 AI角色匹配 Agent 输出可编辑草稿和角色，避免本地章节状态与后端 paragraph 状态错位。
- **AC-LLM-04** 不得为了通过文本守恒测试改写、总结、删除或新增原文。
- **AC-LLM-05** 当前 AI角色匹配批量 Agent 必须支持 `split_and_select`，在同一次严格 JSON 响应内返回子语句文本、角色、置信度和原因。

## 五、TTS 和音频

- **AC-AUDIO-01** 本地 Qwen3-TTS 服务脚本复制到 `backend/tts/qwen3_tts_server.py`。
- **AC-AUDIO-02** 大型 TTS 模型权重不得提交到仓库。
- **AC-AUDIO-03** 音频生成请求必须记录 utterance、role、provider、参考音频、参考文本和输出路径。
- **AC-AUDIO-04** voice cloning 缺少参考音频或参考文本时不得发起 TTS。
- **AC-AUDIO-05** 音频生成必须返回非空、可解码、时长大于 0.5 秒的 wav；真实服务不可用时可返回明确标注的本地占位 wav。
- **AC-AUDIO-06** 前端不得把后端 VoiceJob 原始失败 JSON 直接展示为用户错误。
- **AC-AUDIO-07** 音频样本必须有许可证、来源和 transcript。
- **AC-AUDIO-08** 主页面音频生成请求必须携带并解析当前角色的 `voice_resource_id`，保证使用当前绑定音色的参考音频和参考文本。

## 六、模型配置

- **AC-CONFIG-01** 远端模型配置页只展示 Base URL、模型名称、api_key。
- **AC-CONFIG-02** 本地模型配置页只展示 BASE_URL、模型权重路径。
- **AC-CONFIG-03** 仓库不得提交真实 API key；测试中只能使用明显的占位字符串。

## 七、v0.3.4 AI小说格式解析 / AI角色分析 / AI角色匹配、批量配音和导出

- **AC-V031-01** 选择章节后，章节顶部展示两个独立入口：`AI角色分析` 和 `AI角色匹配`，不得再展示旧的 `AI一键分析` 入口。
- **AC-V031-02** `AI角色分析` 启动 LangGraph 角色分析阶段，自动新增/更新角色、匹配或生成音色并绑定音色，然后暂停等待用户检查角色列表。
- **AC-V025-03** 角色候选展示在 `角色列表` 下方，包含名称、别名/称呼、性别、人设/身份/性格、推荐音色方向、证据片段、置信度和人工确认标记。
- **AC-V031-03** 点击 `AI角色匹配` 后恢复同一个工作流，复用后端整段落语句草稿函数，并由同一个批量角色匹配 Agent 同时完成必要的语句划分和角色选择。
- **AC-V025-05** 已有 `role_id` / `speaker_role_id` 的语句不得被覆盖；仅为空角色语句自动选择角色。
- **AC-V025-06** 多人对白、对白 + 旁白动作 + 对白或对白 + 说话动作时，批量 Agent 必须返回 `split_and_select`，不得依赖独立 AI语句划分服务。
- **AC-V025-07** 每完成一个语句角色选择，都通过前端可消费的流式事件同步。
- **AC-V025-08** 模型 JSON/schema/文本守恒失败必须返回可读失败状态，不得悄悄改写原文。
- **AC-V031-04** AI角色匹配完成后不自动生成音频；用户可点击 `一键生成配音`。

- **AC-V030-10** 空角色语句必须通过批量 LLM JSON 选择角色，已有角色不得被覆盖。
- **AC-V030-11** 当前路径不再接受 `needs_split` 作为分句落库动作；需要分句时必须在本次响应中返回 `split_and_select`。
- **AC-V030-12** 角色分析阶段自动新增/更新角色、自动匹配或生成音色，并保留匹配分数/原因。
- **AC-V030-13** `一键生成配音` 必须按角色/音色分组批量生成，并按语句 ID 回填音频状态。
- **AC-V030-14** `一键导出` 必须导出逐条音频和 manifest；只有全章完成时导出完整拼接音频。
- **AC-V030-15** 角色删除必须阻止被引用角色静默删除，并支持解绑或迁移策略。
- **AC-V032-16** 对 `“都怪你多嘴，她认出我们了。”佩罗恼火道。` 这类对白 + 说话动作段落，`AI角色匹配` 必须在同一次批量 Agent 响应中拆分并匹配；分句后对白归佩罗，说话动作/旁白片段归旁白。
- **AC-V032-17** 删除右侧某个段落时，只删除该段落和该段语句缓存，不得清空其他段落已经完成的 AI角色匹配结果。
- **AC-V033-18** 前端源码不得包含独立 `AI语句划分` 按钮、`AI语句划分进度`、`runAiSegmentationForParagraph` 或段落级 `/segment` 调用。
- **AC-V034-19** 前端按钮文案必须为 `AI小说格式解析`，不得继续展示 `AI章节划分`。
- **AC-V034-20** 前端当前章节工作区必须包含 `当前章节完整小说内容` 和 `划分语句与角色匹配` 两个等宽区域。
- **AC-V034-21** 前端左侧小说章节区必须支持收起/展开，并在收起态变为窄边栏。

## 八、真实环境和复核

- **AC-REAL-01** 模型、TTS、音频和 UI 验收必须优先在真实环境执行。
- **AC-REAL-02** mock 只能用于单元测试，不得替代端到端结论。
- **AC-REAL-03** UI 改动需要真实截图或录屏证据。
- **AC-REAL-04** 音频改动需要真实音频文件、时长、可解码结果和许可证证据。
- **AC-REAL-05** 真实小说样本 `这个地下城长蘑菇了.txt` 必须能按数字编号章节解析。
- **AC-REAL-06** 本地真实音色样本 `年轻男`、`御姐音`、`播音腔女`、`男声旁白` 必须能读取 transcript 并通过 `ffprobe` 解码。
