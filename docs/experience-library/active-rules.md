# Active Rules

这些规则是每次开发前必须读的短规则。只保留高频、关键、容易复犯的问题。

## 当前规则

- 不得降低或绕开 `docs/development/acceptance-standard.md`。
- 不得提交没有许可证和来源记录的音频、文本或图片素材。
- 语句划分必须通过文本守恒校验；模型输出不能改写、总结、删除或新增原文。
- Common Voice Chinese (China) 不得提交原始 clips，只能作为可选本地下载来源。
- 模型权重、API key 和生成输出不得提交到仓库。
- mock 测试不能替代真实模型、真实 TTS、真实 UI 和真实音频证据。
