# NovelVoice-Agent v0.13 Harness Spec

## Goal

v0.13 fixes the v0.12 workbench issues found during real UI use: frontend local chapter paragraphs no longer map to backend paragraph state, utterance controls are unclear, audio preview surfaces raw TTS failures, the voice library cannot scroll, role playback does nothing, roles cannot be added, and model configuration exposes unnecessary fields.

## Main Workflow Changes

- `语句划分` runs against the currently loaded chapter paragraphs and produces local editable utterance drafts, avoiding `paragraph not found` from unsynced backend workbench state.
- Utterance drafts remain nested inside their source paragraph.
- Utterance controls use visible labels: `语句文本`, `选择角色`, `情绪`, `语速`, `音量`, `情感控制文本`.
- The utterance UI removes the `voice_cloning` / `voice_design` selector; role binding decides the voice mode internally.
- The old `音频试听` action becomes `音频生成`.
- Audio generation sends utterance text, selected role, selected role reference audio/reference text, and the human-entered emotional control text.
- If the local Qwen3-TTS service is not running, the API returns a marked substitute wav instead of surfacing raw failed job JSON.

## Role And Voice Library

- Role cards include an icon-only play button for the selected voice resource.
- Role cards can be added from the left sidebar and synced to `/api/roles`.
- The voice library page has its own vertical scroll container.

## Model Configuration

- Remote model UI only contains `Base URL`, `模型名称`, and `api_key`.
- Local model UI only contains `BASE_URL` and `模型权重路径`.
- No real API key may be committed; stored examples and tests must use blanks or obvious placeholders.

## Acceptance

- Clicking `语句划分` after selecting and confirming `1.变成蘑菇的公爵千金` does not show `paragraph not found`.
- No utterance editor control appears without a visible label.
- `voice_cloning` is not shown as a user-facing utterance control.
- Clicking `音频生成` returns either real TTS audio or a clearly marked local substitute wav that is decodable and longer than 0.5 seconds.
- The voice library page scrolls independently.
- The role play icon triggers audio playback for the selected voice resource.
- `新增角色` creates a new editable role card.
- Model configuration shows only the fields listed above.
