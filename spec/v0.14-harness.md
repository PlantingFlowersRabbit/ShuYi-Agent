# NovelVoice-Agent v0.14 Harness Spec

## Goal

v0.14 tightens the workbench around real Qwen segmentation and a safer TTS configuration flow. It fixes stale paragraph confirmation state, changes segmentation from local punctuation splitting to Qwen/Qwen3-8B speaker-unit segmentation, and expands audio/voice/model controls without adding mobile scope.

## Main Workflow Changes

- Confirming a chapter synchronizes the currently visible local paragraph modules to the backend before enabling segmentation, so edits and deletes no longer trigger stale `paragraph not found` responses.
- `语句划分` calls the configured OpenAI-compatible `Qwen/Qwen3-8B` provider for each confirmed paragraph.
- The segmentation prompt emphasizes speaker/role units instead of mechanical sentence boundaries, especially dialogue split by Chinese double quotes.
- Collapsing a paragraph hides the whole paragraph, including nested audio-generation modules.
- Each audio-generation module has top-right `添加音频生成` and `删除音频生成` actions.

## Audio Controls

- `情绪` is a Chinese select list with an empty option.
- `情感控制文本` is renamed to `其他控制文本` and remains a Chinese free-text placeholder field.
- Qwen3-TTS local Base voice cloning accepts reference audio, reference text, `language`, `response_format`, and `x_vector_only`; UI exposes `语言` and `仅使用声纹` beside role, emotion, speed, and volume.
- Speed and volume retain visible range notes: speed `0.5-2.0`, volume `0.0-2.0`.

## Voice Library

- Adding a reference audio file uses a file picker and backend base64 upload, not a typed filesystem path.
- Generated voices are preview-first: generation uses the text description and `语音具体内容`, returns playable audio, and only enters the library after `保存音色`.
- Generated voice progress is shown separately from utterance audio generation progress.

## Model Configuration

- Remote and local model sections each have their own `保存模型配置` button.
- Remote model configuration has `测试链接` against the OpenAI-compatible `/models` endpoint.
- Local model configuration has `启动服务`, which launches `backend/tts/qwen3_tts_server.py` with the saved model path.
- Save, test, and start actions return visible success/failure feedback.

## Scope

- v0.14 is desktop-only. Mobile responsive layout support is intentionally removed.
