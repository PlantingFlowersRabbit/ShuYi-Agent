# NovelVoice-Agent v0.3.4 Harness Spec

## Goal

v0.3.4 reshapes the main frontend workflow around three visible AI agents:

1. `AI小说格式解析`
2. `AI角色分析`
3. `AI角色匹配`

The chapter navigation area can collapse into a left rail. The current chapter workspace shows the full chapter text on the left half and only statement/role-matching output on the right half.

## Required Behavior

- Rename the frontend `AI章节划分` button to `AI小说格式解析`.
- Rename the model configuration section copy from `AI章节划分智能体` to `AI小说格式解析智能体`; the internal `chapter_agent` API key remains stable for compatibility.
- The left chapter area must support collapse and expand controls. In collapsed mode it becomes a narrow rail and the main workspace expands.
- After selecting a chapter, the main workspace must be split into two equal columns:
  - left: `当前章节完整小说内容`, showing the full selected chapter body.
  - right: `划分语句与角色匹配`, showing statement text, role selection, audio generation status, and playback only.
- The visible frontend no longer exposes manual paragraph cards, paragraph folding, paragraph deletion, or a `确认无误` gate.
- `AI角色匹配` must prepare whole-paragraph statement drafts automatically before resuming the role-matching workflow.
- `AI角色匹配` continues to own statement splitting and role selection in the same batch Agent response.
- `一键生成配音` remains user-triggered and must not start automatically after role matching.

## Acceptance

- `pyproject.toml`, `frontend/package.json`, and `frontend/package-lock.json` report `0.3.4`.
- The browser title and main UI title report `NovelVoice-Agent v0.3.4`.
- Repository checks prove the frontend contains `AI小说格式解析` and no longer contains the old `AI章节划分` button copy.
- Repository checks prove the frontend contains the collapsible chapter rail state and the equal-width `chapter-reader` / `statement-panel` workspace.
- Frontend build succeeds with `npm run build`.
- Full automated tests pass with `pytest -q`.
