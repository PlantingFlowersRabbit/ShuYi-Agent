# NovelVoice-Agent v0.251 Harness Spec

## Goal

v0.251 is a targeted patch on top of v0.25. It fixes DeepSeek-compatible model calls for the AI chapter split agent and the AI one-click role-analysis phase without changing the human-led workflow, JSON/schema validation, text-conservation checks, or audio-generation boundaries.

## Required Behavior

- The AI chapter split agent test link accepts a DeepSeek Base URL entered as either `https://api.deepseek.com` or `https://api.deepseek.com/v1`.
- When the user enters a trailing `/v1`, the DeepSeek model-list test calls the root `https://api.deepseek.com/models` endpoint instead of `https://api.deepseek.com/v1/models`.
- `AI一键分析` role analysis uses the `chapter_agent` provider, model, and API key lookup, not the SiliconFlow `llm` segmentation provider.
- The workflow still uses the SiliconFlow `llm` provider for paragraph AI segmentation.
- Existing role IDs are not overwritten, model suggestions remain editable, and the workflow does not automatically generate audio.
- JSON/schema/text-conservation failures remain readable failures and must not be silently repaired by rewriting source text.

## Acceptance

- `pyproject.toml` and `frontend/package.json` report `0.251.0`.
- The main UI title reports `NovelVoice-Agent v0.251`.
- Automated tests cover DeepSeek `/v1` Base URL normalization for the chapter-agent test link.
- Automated tests cover `AI一键分析` role analysis using the configured DeepSeek chapter-agent provider before the workflow pauses for role-list completion.
