# NovelVoice-Agent v0.3.0 Harness Spec

## Goal

v0.3.0 upgrades the AI one-click analysis and dubbing workflow from a candidate-only, per-utterance role-selection flow into a batch-oriented chapter workflow with automatic role/voice preparation, grouped TTS generation, export, and safer role management.

## Required Behavior

- `AI一键分析` still starts the LangGraph workflow and preserves the existing pause before downstream sentence role selection, but the role-analysis node now automatically adds or updates candidate roles, deduplicates narrator/existing aliases, matches voices, and generates a voice resource when the library has no suitable match.
- Existing `role_id` / `speaker_role_id` values are never overwritten during batch role selection.
- Blank-role statements are selected through a batch role-selection API (`choose_roles_batch`) using strict JSON `items`, not one LLM call per statement on the main path.
- Batch decisions support `select_role`, `needs_split`, `uncertain`, and `skip`; `needs_split` reuses the existing AI statement segmentation service before retrying blank statements.
- Invalid batch JSON fails the batch without writing half-trusted role assignments.
- `一键生成配音` generates the current chapter by grouping pending statements by `voice_resource_id` / role, calling batch TTS per group, skipping successful existing audio, and mapping results back by `statement_id`.
- Qwen3-TTS local server exposes `/v1/audio/speech-batch`, reusing one voice-clone prompt for a batch under the same reference audio.
- `一键导出` exports per-statement audio files plus `manifest.json`; it only writes `chapter_full.wav` when every required statement has completed audio.
- Role cards and voice resources include expanded metadata: aliases, gender, profile/persona, voice description, suitable role types, reference audio, preview/playable audio, match score/reason, and AI-generated voice marker.
- Role deletion blocks referenced roles unless the user chooses to unbind or migrate references.

## Acceptance

- `pyproject.toml` and `frontend/package.json` report `0.3.0`.
- The main UI title reports `NovelVoice-Agent v0.3.0`.
- Automated tests cover batch role selection non-overwrite, one batch call for multiple statements, `needs_split`, invalid JSON no-write, auto role/voice creation, grouped batch dubbing, export manifest/full-audio gate, and role deletion constraints.
- Frontend build succeeds after adding `AI一键分析`, `一键生成配音`, `一键导出`, expanded role/voice fields, and visible progress/status feedback.
