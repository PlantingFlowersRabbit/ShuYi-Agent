# NovelVoice-Agent v0.22 Harness Spec

## Goal

v0.22 extends the AI chapter splitting agent so the same workflow can process TXT files with legacy Chinese encodings and
EPUB novels. The agent must still prove that it can reuse known scripts first, call the chapter-splitting skill for
unseen formats, write a reusable script, and validate the result before accepting it.

## File Input

- Frontend upload accepts `.txt` and `.epub`.
- TXT uploads are decoded from bytes with UTF-8 first, then legacy Chinese encodings such as GB18030/GBK.
- EPUB uploads are sent to the backend as base64; the browser does not parse ZIP files.
- Backend extracts EPUB text from `META-INF/container.xml`, OPF manifest/spine order, and XHTML chapter bodies.
- The extracted EPUB text is fed into the same AI chapter splitting agent as TXT.

## Agent Behavior

- Curated parser scripts run before `agent_generated_*.py` scripts, so bad cached generated scripts cannot block known
  formats.
- The curated Chinese parser supports CRLF line endings and `第X卷 标题` style headings, including `1973.txt`-style text.
- Unknown heading styles trigger the skill, generated script persistence, rule validation, and AI review before acceptance.

## Acceptance

- `/api/novels/ai-chapter-split-file` accepts `filename` and `content_base64` for TXT/EPUB files.
- EPUB fixture text is extracted in spine order and split into chapters.
- The real local EPUB `这个地下城长蘑菇了.epub` can be extracted and split without mojibake.
- The frontend shows an EPUB preview message instead of rendering binary or garbled text.
