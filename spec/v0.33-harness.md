# NovelVoice-Agent v0.3.3 Harness Spec

## Goal

v0.3.3 removes the standalone frontend `AI语句划分` feature and folds statement splitting into `AI角色匹配`. Role matching now asks the same batch Agent to split mixed statements and assign roles in one strict JSON response.

## Required Behavior

- The main chapter UI must not expose an `AI语句划分` button, progress bar, status copy, or frontend call to `/api/paragraphs/{paragraph_id}/segment`.
- Clicking `确认无误` still creates one editable whole-paragraph utterance draft per paragraph.
- Clicking `AI角色匹配` sends blank-role statements to the batch role-matching Agent.
- If a statement contains mixed text such as dialogue plus a speech tag, the Agent must return `action="split_and_select"` with ordered `utterances`.
- A `split_and_select` response must preserve the original statement text when its child utterance texts are concatenated, allowing only whitespace differences.
- Each split child utterance must include its own `role_id`, `confidence`, and `reason`; valid roles are applied immediately without calling the standalone segmentation service.
- Speech tags outside quotation marks, for example `佩罗恼火道。`, must be treated as narrator-owned even if a model overmatches the mentioned character.
- Legacy `needs_split` is no longer a valid current-path action for AI role matching; the Agent must return `split_and_select` instead.
- Deleting one paragraph must continue to remove only that paragraph's utterance cache and preserve other paragraphs' AI role matching results.

## Acceptance

- `pyproject.toml`, `frontend/package.json`, and `frontend/package-lock.json` report `0.3.3`.
- The browser title and main UI title report `NovelVoice-Agent v0.3.3`.
- Backend tests prove `AI角色匹配` can split and select roles in one batch response without calling the standalone segmentation service.
- Backend tests cover `“都怪你多嘴，她认出我们了。”佩罗恼火道。`, ensuring the dialogue is assigned to 佩罗 while the trailing speech tag is assigned to 旁白.
- Frontend repository checks prove the standalone `AI语句划分` button, progress label, function, and paragraph segment endpoint call are absent.
- Existing v0.3.1 split-button flow, v0.3.0 batch dubbing/export behavior, and v0.3.2 paragraph deletion preservation continue to pass.
