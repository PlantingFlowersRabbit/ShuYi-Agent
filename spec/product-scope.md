# 产品范围

## 用户和场景

目标用户是希望把小说章节拆成可配音脚本的创作者。v0.1 服务的是“人工校正 + AI 辅助”的单人工作流：用户知道小说内容，愿意逐段确认和修正，但不希望手工复制粘贴每一句、手工维护角色和每条音频。

## 核心对象

- `NovelFile`：用户导入的 txt 小说文件。
- `Chapter`：由章节正则拆出的章节。
- `Paragraph`：由段落正则拆出的正文块，可折叠、编辑、删除。
- `RoleCard`：角色姓名、简介、voice cloning 音频、参考文本或 voice design prompt。
- `Utterance`：由 LLM 或人工拆出的配音子语句。
- `VoiceJob`：一次 TTS 试听或生成请求。

## v0.1 范围内能力

- 固定格式 txt 导入和本地解析。
- 章节列表展示和选择。
- 章节正文按段落展示。
- 段落编辑、折叠和删除。
- 段落确认门禁。
- 单段或多段 LLM 语句划分。
- 子语句人工校正。
- 角色卡新增、编辑、删除和同步。
- voice cloning 与 voice design 两种声音模式的 UI 和请求合约。
- 本地 TTS 服务调用合约和单条试听。
- 样本素材、许可证和真实环境验收记录。

## v0.1 范围外能力

- 非固定格式小说智能识别。
- EPUB、PDF、Word、网页导入。
- 自动角色关系抽取。
- 自动人物声音分配。
- 长任务队列、并发批量生成、云端存储。
- 自动音频拼接成整章成品。
- 远程 TTS API 生产接入。
- 商业授权素材库。
- 用户账户、权限、分享、发布。

## 后续版本预留

后续版本可以增加 harness 自动化：

- 从导入到全章音频的自动任务图。
- 自动 agent 检查章节、段落、语句和角色一致性。
- 自动调用 reviewer 复核模型输出。
- 自动根据失败经验更新提示词、校验器和回归用例。
- 远程 TTS provider 和多模型路由。

这些预留必须通过稳定数据模型、provider registry、验收标准和经验库完成，不能在 v0.1 中提前硬写复杂编排。
