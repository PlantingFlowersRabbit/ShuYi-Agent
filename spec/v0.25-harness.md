# NovelVoice-Agent v0.25 Harness Spec

## Goal

v0.25 adds an AI one-click analysis workflow for a selected chapter. The workflow remains human-led: it analyzes role candidates first, pauses for the user to add or bind roles, then resumes to create editable utterance drafts, split ambiguous paragraphs, and select roles only where `role_id` / `speaker_role_id` is blank.

## Workflow

- After AI chapter splitting and chapter selection, the chapter header shows `AI一键分析` to the left of `确认无误`.
- Clicking `AI一键分析` starts a LangGraph workflow and analyzes the current visible chapter paragraphs for dubbing roles, including narrator.
- Role suggestions are shown under `角色列表` with name, aliases, gender, profile/personality, recommended voice direction, evidence, confidence, and human-review flag.
- The workflow pauses with the message asking the user to add needed roles to the role list or bind candidates to existing roles.
- The UI shows `角色列表添加完成`; clicking it resumes the same workflow.
- Resuming generates whole-paragraph utterance drafts using the same backend function used by the `确认无误` flow.
- For each paragraph, existing utterances with non-empty `speaker_role_id` are never overwritten.
- For blank-role utterances, the agent either selects the best existing role or calls the existing backend AI segmentation service for multi-speaker / ambiguous paragraphs.
- After AI segmentation, the workflow re-runs role selection only for utterances whose role is still blank.
- Each successful role selection is streamed to the frontend as an NDJSON `role_selected` event.
- The workflow never generates audio automatically.

## Validation

- Model role suggestions and role selections are editable suggestions, not facts.
- AI segmentation continues to use strict JSON/schema/text-conservation validation.
- If JSON/schema/text conservation fails, the workflow returns a readable failed status and does not silently rewrite source text.
- Frontend never simulates clicks to reuse `AI语句划分`; buttons and workflow nodes share backend services.

## Acceptance

- `pyproject.toml` and `frontend/package.json` report `0.25.0`.
- The main UI title reports `NovelVoice-Agent v0.25`.
- Backend exposes `/api/chapters/{chapter_id}/ai-one-click-analysis/start`, `/api/ai-one-click-analysis/{thread_id}/roles-completed`, and `/api/ai-one-click-analysis/{thread_id}/roles-completed-stream`.
- Confirming paragraphs returns backend `utterance_drafts`; the frontend uses those drafts instead of locally simulating the confirm logic.
- Automated tests cover workflow pause, role candidates, resume role preservation, segmentation failure status, streamed role-selection events, and v0.25 UI strings.
