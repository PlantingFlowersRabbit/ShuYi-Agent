# NovelVoice-Agent v0.12 Harness Spec

## Goal

v0.12 optimizes the v0.11 workbench for large novels. Uploading a full novel must not cause the browser to render or
split large chapter bodies before the user asks for them.

## Main Workflow

- Uploading a novel only reads the file, stores the full text outside rendered UI state, and shows a short opening preview.
- The old `确认划分章节` button is renamed to `划分章节`.
- `划分章节` generates a lightweight chapter index and updates a chapter-splitting progress bar.
- The right panel must not show any specific chapter content before `划分章节` is clicked.
- After the chapter index is available, the right panel still stays in an empty state until the user selects a chapter.
- Selecting a chapter extracts only that chapter body from the stored full text and then splits paragraphs for that chapter.
- Upload, chapter splitting, utterance segmentation, and voice generation each have a visible progress bar.

## Layout

- The page shell itself should not be the primary scroll container.
- The left sidebar and right main panel must have independent vertical scrollbars.
- Mobile layout may stack panels, but each panel must avoid horizontal overflow and text overlap.

## Performance Reason

Rendering the full novel in a controlled textarea and immediately parsing/loading the first chapter makes large samples
feel stuck. v0.12 avoids this by keeping the full text in a ref, rendering only a short preview, and lazily extracting
chapter content when a chapter is selected.

## Acceptance

- The real sample `这个地下城长蘑菇了.txt` can be uploaded without rendering its full text in the sidebar.
- Before `划分章节`, the right panel shows only an empty state.
- After `划分章节`, the left chapter list appears quickly.
- After selecting `1.变成蘑菇的公爵千金`, only that chapter is loaded into the right panel.
