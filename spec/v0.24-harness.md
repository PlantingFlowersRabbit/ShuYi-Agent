# NovelVoice-Agent v0.24 Harness Spec

## Goal

v0.24 changes utterance segmentation from a chapter-level action into a paragraph-local `AI语句划分` workflow. It also
fixes the role/voice binding path so a newly selected voice resource, such as `男2`, is the reference used by main-page
speech generation.

## AI Utterance Segmentation

- Clicking `确认无误` synchronizes the current chapter paragraphs and immediately creates one editable utterance draft per
  paragraph, with the entire paragraph copied into `语句文本`.
- The old chapter-level `语句划分` button is removed from the chapter header.
- Each paragraph toolbar shows `AI语句划分` between the paragraph id and `折叠`.
- Clicking a paragraph's `AI语句划分` analyzes only that paragraph and replaces that paragraph's utterance drafts.
- Segmentation focuses on speaker/role units rather than punctuation-only sentence units.
- Dialogue/narration/dialogue text such as
  `“别笑了，引来魔物就麻烦了。”佩罗不耐烦地打断了笑声，“就这了，把她放下来。”` should be split into three
  voice units.
- Continuous dialogue from one speaker inside the same Chinese double quotes should stay as one voice unit.

## Agent

- The backend AI segmentation path uses LangChain with the SiliconFlow default
  `base_url="https://api.siliconflow.cn/v1"` and `model="Qwen/Qwen3-8B"`.
- The agent keeps the existing strict JSON schema and text-conservation validation.
- If the first model output fails validation, the agent performs one reflection attempt with the validation error,
  original paragraph, known roles, and first output.
- Invalid output after reflection is returned as a failed editable draft path rather than silently changing source text.

## Voice Binding

- Main-page `音频生成` includes the current role's `voice_resource_id`.
- The speech endpoint resolves that resource at generation time and uses its `reference_audio_path` and
  `reference_text` even if the backend role cache has not yet caught up with the UI.
- A role named `旁白2` bound to voice `男2` with `outputs/audio/preview-0002.wav` must call TTS with that reference
  audio and the voice resource's `语音具体内容`.

## Acceptance

- `pyproject.toml` and `frontend/package.json` report `0.24.0`.
- The main UI title reports `NovelVoice-Agent v0.24`.
- Confirming paragraphs produces whole-paragraph utterance drafts without calling the remote model.
- `AI语句划分` appears on every paragraph card and calls `/api/paragraphs/{paragraph_id}/segment` for only that
  paragraph.
- The LangChain/reflection segmentation agent has automated coverage for a failed first pass followed by a valid
  reflected result.
- Speech generation has automated coverage proving a selected voice resource override supplies the reference audio and
  reference text.
