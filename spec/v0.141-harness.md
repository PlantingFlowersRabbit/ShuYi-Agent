# NovelVoice-Agent v0.141 Harness Spec

## Goal

v0.141 is a targeted follow-up to v0.14. It makes status feedback visible on the model and voice-library pages, explains why generated voice previews may fall back to a placeholder wav, and documents the `仅使用声纹` control.

## Changes

- Model configuration page shows visible feedback for remote/local `保存模型配置`, `测试链接`, and `启动服务`, including failure states.
- Voice library page shows visible feedback for `保存音色` and `删除选中音色`, including failure states and empty-selection handling.
- `生成音色` first attempts the local Qwen3-TTS VoiceDesign endpoint `/v1/audio/voice-design`.
- If VoiceDesign is unavailable, the API returns a playable placeholder wav plus a clear explanation that `Qwen3-TTS-12Hz-1.7B-VoiceDesign` is required for text-description voice generation.
- `仅使用声纹` has an inline Chinese note explaining that it uses only the speaker embedding extracted from the reference audio and tries to ignore reference emotion/prosody.

## Model Boundary

- `Qwen3-TTS-12Hz-1.7B-Base` supports voice cloning from reference audio and reference text.
- Text-description voice generation requires a VoiceDesign-capable model, expected as `Qwen3-TTS-12Hz-1.7B-VoiceDesign`.
